# Taskiflo Website

Public website for Taskiflo, an approval-first AI marketing automation platform for Shopify stores.

## What Taskiflo Does

Taskiflo detects store and customer signals, drafts marketing work, checks risky claims, and holds every customer-facing action for owner approval.

Core workflows:

- Shopify product campaign drafts
- Instagram and Facebook post or reply drafts
- Gmail customer reply drafts
- Approval inbox and safety checks
- Content calendar and activity history
- App-review pages for privacy, terms, data deletion, support, FAQ, and submission assets

## Run

```bash
npm.cmd install
npm.cmd run dev
```

## Build

```bash
npm.cmd run build
```
