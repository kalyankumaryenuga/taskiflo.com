# Taskiflo

Taskiflo is an approval-first AI marketing automation website for Shopify merchants.

The site includes a polished public homepage plus review-ready pages for app platform submissions:

- Privacy policy
- Terms of service
- Data deletion instructions
- Support
- FAQ
- App store submission assets

## Run Locally

```bash
npm.cmd install
npm.cmd run dev:vite
```

Open the local Vite URL shown in the terminal.

## Build

```bash
npm.cmd run build
```

## Submission URLs

Use these routes once the site is deployed:

- `https://taskiflo.com/privacy`
- `https://taskiflo.com/terms`
- `https://taskiflo.com/data-deletion`
- `https://taskiflo.com/support`
- `https://taskiflo.com/faq`
- `https://taskiflo.com/app-store-assets`
